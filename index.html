What You Will Learn

🧠

What is an Agent?

An AI system that perceives its environment, makes decisions and takes actions to reach a goal.

🛠️

Tool Use

Agents call APIs, search the web, run code and read files to get work done.

🗺️

Planning

Breaking big goals into small steps and adjusting the plan as results come in.

💾

Memory

Short-term context and long-term memory let agents remember past work.

🤝

Multi-Agent Systems

Several specialized agents working together, each handling one part of a task.

🔒

Safety & Control

Permissions, human approval and guardrails that keep agents reliable.
